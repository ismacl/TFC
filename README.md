## 🚀 Descripción
Aplicación web para gestionar entrenamientos y tecnicas de Brazilian Jiu-Jitsu(BJJ).
Permite a los usaurios registrarse, iniciar sesión, editar su perfil y cinturón, añadir y visualizar entrenamientos, consultar técnicas y contactar fácilmente.
Todo con un diseño moderno y pensado para mejorar la experiencia del usuario.

## 🔨 Funcionalidades del proyecto
- 🔐 **Registro/Login**: Acceso seguro y rápido.
- 😃 **Perfil personal**: Datos del usuario y edición del cinturón.
- 📆 **Entrenamientos**: Añadir, visualizar y gestionar entrenamientos.
- 💻 **Técnicas**: Listado organizado.

## 📦 Instalación
Para ejecutar el proyecto en tu entono local:

1. **Clona el repositorio**

2. **Configura el servidor local**
    - Usa XAMPP o cualquier servidor con soporte PHP y MySQL.
    - Copia la carpeta del proyecto dentro de htdocs (si usas XAMPP).

3. **Configura la base de datos**
    - Abre phpMyAdmin.
    - Crea una nueva base de datos.
    - Importa el archivo .sql incluido en el proyecto para generar las tablas.
    - Ajusta las credenciales en el archivo config.php.

4. **Accede a la aplicación**
    - Abre tu navegador y entra en la aplicación.
